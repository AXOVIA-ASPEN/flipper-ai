Feature 25 · Subscriptions (In-App Purchase) · Phase C

Native billing, one source of truth.

FLIPPER and PRO subscriptions sell through Apple and Google's native billing (mediated by RevenueCat) and reconcile to the same backend tier record as web Stripe subscriptions — a web subscriber is never double-billed on mobile.
