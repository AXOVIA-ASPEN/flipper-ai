Feature 17 · Sign-In & Onboarding · Phase A

One identity, web and mobile.

Email/password, Google, and Apple sign-in against the same Firebase project as the web app. Sessions persist securely across launches, with optional Face ID / fingerprint unlock.

Same Firebase identity
